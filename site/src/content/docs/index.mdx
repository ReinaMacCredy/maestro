Maestro keeps a small, durable record next to your code. Each repository gets
a SQLite store under `.maestro/` that holds work items, decisions, sessions,
and the proof each item was closed with. Agents in Claude Code and Codex read
and write it through one command, `maestro`.

## At a glance

- A work item (a card) is one bounded task. `maestro work add "<title>"
  --start` creates and claims it, and `maestro work done <id> --check
  "<command>"` closes it with the result of a command Maestro runs.
- `maestro work list` shows what is open, who holds it, and what blocks it.
- `maestro decision add "<text>" --rationale "<why>"` records a settled
  choice in one command.
- A bundle (`SPEC.md`, `NOTES.md`, `VERIFY.md`) carries large or risky work
  across sessions and archives itself when its last card is done.
- Recipes and skills are methods in Markdown that agents read on demand.
- SLP, the optional team layer, runs a Lead and its Peers as separate agent
  sessions in panes of Herdr, a terminal workspace for agents, under your Hub
  agent. It is a plugin that is off by default.
