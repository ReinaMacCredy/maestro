Maestro separates durable coordination from live team conversation. It stores
work, decisions, lifecycle and minimal activity in each owning store, while
Herdr provides the running workspace and panes.

## SLP v2 at a glance

- Five roles: Hub Supervisor, Team Supervisor, Lead, Peer and Observer.
- Direct Team Supervisor, Lead and Peer conversation; the supported Hub flow
  speaks only through Team Supervisor.
- Nine public SLP operations.
- One work lifecycle: `OPEN → ACTIVE → RETURNED → DONE`.
- One canonical `~/maestro/SLP.md`, pinned into each project generation.
- Optional foreground Watch Pane with runtime-only transcript.
- One sentinel per generation that prompts the Observer every five minutes;
  the Observer's only note is `work note --stall`.
