Maestro is a local-first coordination system for human and agent work. It keeps
durable work, decisions, sessions, evidence, dispatches, and handbacks in each
repository's shared Git root. It is written in TypeScript, runs on Bun, and does
not require a background service.

## Install

Install Maestro from its source repository:

```sh
curl -fsSL https://maestro.maccredyreina.me/install.sh | sh
```

The installer creates a source checkout that `maestro update` can
fast-forward, installs the runtime and shim, wires the current repository, and
registers it with the Supervisor room.
