# TDD

Execute-only RED/GREEN practice for one behavior-changing Step. Load only the
typed children explicitly required by the intent: TestDesign,
InterfaceDesign, Mocking, Refactoring, or DeepModules. Every child requires
TDD in the same Execute closure; no job admits a child directly, and missing
need evidence never falls back to loading all children.
