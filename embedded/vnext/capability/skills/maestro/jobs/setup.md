# Setup job

Consume exact bootstrap or Packet facts and the shared Setup-mode resolution.
Supply exactly `Require(mode)` or `AcceptUniqueEligible`; omission, prose,
flags, paths, prior results, and adapter defaults construct neither. The shared
resolver derives the complete eligible set from one coherent typed locality,
applies the request, and only then validates the already advertised Operation.
An Operation never adds, removes, ranks, or breaks a tie between modes.
RollbackDistributionTransaction, RecoverDistributionTransaction, and recovery
or reconciliation Operations establish no ordinary Setup mode. Do not infer a
mode, target, custody, authority, currentness, retry right, or persistence.
