# HTML and CSS style

Follow the project's design system and browser support matrix.

- Use valid semantic HTML, UTF-8, lowercase elements and attributes, and HTTPS
  resources. Provide useful alternative text and media captions.
- Preserve keyboard navigation, focus visibility, labels, landmarks, contrast,
  reduced-motion behavior, and responsive zoom.
- Separate structure, presentation, and behavior unless the framework owns a
  component boundary.
- Prefer meaningful class names, class selectors, custom properties, and the
  cascade over ID selectors or `!important`.
- Use consistent two-space formatting, quoted attributes, unitless zero, and
  semicolons for declarations.
- Verify narrow and wide layouts, populated and empty states, keyboard use,
  and the real browser path.
